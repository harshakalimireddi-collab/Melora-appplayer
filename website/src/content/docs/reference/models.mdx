## Image

Following is the structure of the `meloraImageObject`:

| Property | Type            |
| -------- | --------------- |
| width    | `int` or `null` |
| height   | `int` or `null` |
| url      | `string`        |

## User

Structure of the `meloraUserObject`, which is used to represent a user in melora returned by melora Plugins.

| Property    | Type                                               |
| ----------- | -------------------------------------------------- |
| id          | `string`                                           |
| name        | `string`                                           |
| externalUri | `string`                                           |
| images      | List of [`meloraImageObject`][meloraImageObject] |

> `externalUri` is a URL that points to the user's profile on the external service (e.g. Listenbrainz)

## Artist

### meloraSimpleArtistObject

Following is the structure of the `meloraArtistObject`:

| Property    | Type                                                         |
| ----------- | ------------------------------------------------------------ |
| id          | `string`                                                     |
| name        | `string`                                                     |
| externalUri | `string`                                                     |

### meloraFullArtistObject

Following is the structure of the `meloraFullArtistObject`:

| Property    | Type                                                  |
| ----------- | ----------------------------------------------------- |
| id          | `string`                                              |
| name        | `string`                                              |
| externalUri | `string`                                              |

## Album

### meloraSimpleAlbumObject

Following is the structure of the `meloraAlbumObject`:

| Property    | Type                                                             |
| ----------- | ---------------------------------------------------------------- |
| id          | `string`                                                         |
| name        | `string`                                                         |
| externalUri | `string`                                                         |
| images      | List of [`meloraImageObject`][meloraImageObject]               |
| albumType   | `album`, `single` or `compilation`                               |
| artists     | List of [`meloraSimpleArtistObject`][meloraSimpleArtistObject] |
| releaseDate | `string` (YYYY-MM-DD format) or `null`                           |

### meloraFullAlbumObject

Following is the structure of the `meloraFullAlbumObject`:

| Property    | Type                                                             |
| ----------- | ---------------------------------------------------------------- |
| id          | `string`                                                         |
| name        | `string`                                                         |
| externalUri | `string`                                                         |
| images      | List of [`meloraImageObject`][meloraImageObject]               |
| albumType   | `album`, `single` or `compilation`                               |
| artists     | List of [`meloraSimpleArtistObject`][meloraSimpleArtistObject] |
| releaseDate | `string` (YYYY-MM-DD format)                                     |
| totalTracks | `number`                                                         |
| recordLabel | `string` or `null`                                               |

## Track

Following is the structure of the `meloraFullTrackObject`:

| Property                     | Type                                                             |
| ---------------------------- | ---------------------------------------------------------------- |
| id                           | `string`                                                         |
| name                         | `string`                                                         |
| externalUri                  | `string`                                                         |
| artists                      | List of [`meloraSimpleArtistObject`][meloraSimpleArtistObject] |
| album                        | [`meloraSimpleAlbumObject`][meloraSimpleAlbumObject]           |
| durationMs (in milliseconds) | `number`                                                         |
| explicit                     | `boolean`                                                        |
| [isrc][isrc_wiki]            | `string`                                                         |

> `isrc` stands for International Standard Recording Code, which is a unique identifier for tracks.
> It is used to identify recordings and is often used in music distribution and royalty collection. The format is typically a 12-character alphanumeric code.

## Playlist

Following is the structure of the `meloraSimplePlaylistObject`:

| Property    | Type                                                         |
| ----------- | ------------------------------------------------------------ |
| id          | `string`                                                     |
| name        | `string`                                                     |

| Property      | Type                                                         |
| ------------- | ------------------------------------------------------------ |
| id            | `string`                                                     |
| name          | `string`                                                     |
| description   | `string`                                                     |
| externalUri   | `string`                                                     |
| images        | List of [`meloraImageObject`][meloraImageObject] or `null` |
| owner         | [`meloraUserObject`][meloraUserObject]                     |

## Search Response

Following is the structure of the `meloraSearchResponseObject`:

| Property  | Type                                                                 |
| --------- | -------------------------------------------------------------------- |
| albums    | List of [`meloraSimpleAlbumObject`][meloraSimpleAlbumObject]       |
| artists   | List of [`meloraFullArtistObject`][meloraFullArtistObject]         |
| playlists | List of [`meloraSimplePlaylistObject`][meloraSimplePlaylistObject] |
| tracks    | List of [`meloraFullTrackObject`][meloraFullTrackObject]           |

## Browse Section

Following is the structure of `meloraBrowseSectionObject`:

| Property    | Type             |
| ----------- | ---------------- |
| id          | `string`         |
| title       | `string`         |
| externalUri | `string`         |
| browseMore  | `boolean`        |
| items       | List of `Object` |

The `items` property array can contain multiple type of `Object` in it but it will always be

- [`meloraFullPlaylistObject`][meloraFullPlaylistObject]
- [`meloraFullAlbumObject`][meloraFullAlbumObject]
- [`meloraFullArtistObject`][meloraFullArtistObject]

## Pagination Response

`meloraPaginationResponseObject` is generic model. The `items` property can contain any type of `Object` in it.

This is the structure of `meloraPaginationResponseObject`:

| Property   | Type                                            |
| ---------- | ----------------------------------------------- |
| limit      | `number`                                        |
| nextOffset | `number` or `null`                              |
| total      | `number`                                        |
| hasMore    | `boolean`                                       |
| items      | List of generic type `T` which extends `Object` |
